# Code of Conduct

## Scope

This applies to issues, pull requests, discussions and any other project space.

## Expected behaviour

- Assume good faith and argue about the code, not the person.
- Give reproduction steps and evidence when reporting a problem.
- Accept that a maintainer may decline a change that widens scope or weakens a
  documented limitation.

## Unacceptable behaviour

- Harassment, insults, or discriminatory language of any kind.
- Publishing another person's credentials, camera identifiers, recordings,
  network details or other private data.
- Posting working exploits or unvalidated security findings in public issues.
  Report those privately as described in [SECURITY.md](SECURITY.md).
- Sustained disruption of technical discussion.

## Enforcement

Maintainers may edit or remove contributions that break these rules and may
block repeat offenders. Report a concern privately to the repository owner
through a channel already established with them.

## Attribution

This is a short project-specific policy, not the Contributor Covenant. Adopt
the full Contributor Covenant if this project grows a contributor base.
